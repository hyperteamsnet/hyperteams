# HyperTeams

**Claude Code 여러 대를 한 화면에서 팀처럼 굴리세요.**

HyperTeams는 내 컴퓨터에 설치된 **Claude Code**를 웹 화면에서 시키고 지켜보는
관제실입니다. 작업할 폴더를 등록해두고 여러 가지 일을 한꺼번에 맡긴 뒤,
진행 상황과 결과를 책상에서든 폰에서든 한눈에 확인합니다.

🌐 **[hyperteams.net](https://hyperteams.net)** · English docs:
[README.md](README.md)

---

## 왜 HyperTeams인가

- **한 화면에서 여러 일을 동시에.** 창을 여러 개 띄우고 옮겨다닐 필요가
  없습니다. 맡긴 일마다 카드가 하나씩 생기고, 전체 상황이 한눈에 보입니다.
- **내 컴퓨터에서, 내 파일로.** 작업은 내 실제 프로젝트 폴더에서, 늘 쓰던
  환경 그대로 진행됩니다.
- **새로 가입할 것이 없습니다.** 이미 쓰고 있는 Claude Code 로그인을 그대로
  씁니다. 따로 만들 계정도, 발급받을 키도 없습니다.
- **1분이면 시작.** 설치 한 줄, 실행 한 줄이면 끝입니다.
- **폰이 곧 관제실.** 밖에서 일을 걸어두고, 이동 중에 진행 상황을 보고,
  자리를 비운 동안에도 작업이 계속 돌아갑니다.

## 이런 걸 할 수 있습니다

| 기능 | 어떻게 도움이 되나 |
|---|---|
| **여러 일을 동시에** | 폴더를 등록해두고 각각에 다른 일을 맡깁니다. 전부 한 대시보드에서 함께 돌아갑니다. |
| **진행 상황이 실시간으로** | 무엇을 하고 있는지, 어떤 파일을 건드렸는지가 그때그때 화면에 나타납니다. 새로고침할 필요가 없습니다. |
| **쓴 만큼 바로 확인** | 일마다 사용량과 비용이 기록되어, 어떤 작업에 얼마가 들었는지 언제든 볼 수 있습니다. |
| **작업 창을 그대로 유지** | 명령을 입력하는 창이 화면을 닫거나 새로고침해도 그대로 살아 있습니다. 만들어진 결과물을 주소 하나로 바로 열어볼 수도 있어, 동료나 내 폰에서 확인하기 좋습니다. |
| **정해둔 시간에 자동 실행** | 매일 밤 정리, 아침 요약처럼 반복되는 일을 시간을 정해 맡겨둘 수 있습니다. |
| **파일 보고 고치고 저장까지** | 폴더 안을 둘러보고, 화면에서 바로 파일을 고치고, 바뀐 내용을 확인해 기록으로 남기는 것까지 한자리에서 합니다. |
| **폰 화면을 먼저 생각한 디자인** | 작은 화면 기준으로 만들어서, 폰에서 쓰는 경험이 곁다리가 아닙니다. |
| **기록이 남습니다** | 주고받은 내용과 사용량이 내 컴퓨터에 저장되어, 껐다 켜도 그대로 이어집니다. |

### 용어 몇 가지

| 용어 | 뜻 |
|---|---|
| **작업 폴더** | 일을 시킬 폴더. 경로만 등록하면 됩니다(없으면 자동으로 만들어 줍니다). |
| **업무** | 한 작업 폴더에 내리는 하나의 지시. |
| **터미널** | 작업 폴더에서 계속 열려 있는 명령 입력 창. |
| **예약 실행** | 정해둔 시간에 업무를 시작하거나 명령을 실행하는 예약. |

## 시작하기

### 1. 준비물

- **Claude Code** — HyperTeams가 시키는 대상입니다. 아래 한 줄로 설치한 뒤,
  터미널에서 `claude` 를 한 번 실행해 로그인해 두세요.

  ```bash
  # macOS / Linux
  curl -fsSL https://claude.ai/install.sh | bash
  ```
  ```powershell
  # Windows PowerShell
  irm https://claude.ai/install.ps1 | iex
  ```

  `claude --version` 이 버전을 보여주면 준비 완료입니다. HyperTeams는 이 로그인을
  그대로 쓰므로 따로 키를 넣을 일이 없습니다.

**그 외 모델은 선택이고, 손으로 설치할 것이 없습니다.** 업무를 Claude Code 대신
GPT · Gemini · Grok · DeepSeek · Kimi 나 직접 띄운 로컬 서버에서 돌릴 수 있습니다.
**전역 설정 → 그 외 모델**을 열어 설치를 누르고 쓰고 싶은 프로바이더의 API 키를
넣어 두면 됩니다. HyperTeams가 실행기를 `~/.hyperteams/pi/` 로 내려받고, 키는 이
컴퓨터에만 둡니다. 그러면 업무를 만들 때 엔진이 하나 더 보입니다.

이 엔진은 Claude Code 보다 작은 껍데기라 서브에이전트도, MCP 도, 권한 모드도,
백그라운드 셸도 없습니다 — 그래서 이 엔진으로 도는 업무에서는 그 조작들이
숨겨집니다. 업무의 엔진은 시작하면 고정입니다. 이어하기는 같은 세션을 다시
잇는 것이고, 세션은 그것을 만든 엔진의 것입니다.

- **Node.js** — 앱을 돌리는 것이 Node 입니다.
  [nodejs.org](https://nodejs.org/) 의 LTS 를 설치하고 `node --version` 으로
  확인하면 됩니다. 패키지 관리자를 쓴다면 이렇게 됩니다.

  ```powershell
  # 윈도우 — winget 은 윈도우에 이미 들어 있어 따로 준비할 것이 없습니다
  winget install OpenJS.NodeJS.LTS
  ```
  ```bash
  # 맥 — Homebrew
  brew install node
  ```
  ```bash
  # 리눅스 — 배포판 기본 패키지는 버전이 뒤처져 있는 경우가 많습니다.
  # fnm(github.com/Schniz/fnm) 이나 nvm(github.com/nvm-sh/nvm) 을 권합니다
  fnm install --lts && fnm use --lts
  ```

  윈도우에서 Chocolatey 를 쓴다면 두 가지가 다릅니다 — **관리자 권한
  PowerShell** 이어야 하고, Chocolatey 자체를 까는 한 줄에
  `Set-ExecutionPolicy Bypass -Scope Process -Force` 가 들어갑니다. 이름 그대로
  그 창에서만 유효하고 창을 닫으면 원래대로 돌아가므로, 시스템 설정을 영구히
  바꾸는 것이 아닙니다.

  ```powershell
  choco install nodejs-lts -y
  ```

  윈도우는 설치가 끝나면 **새 터미널 창**을 열어야 `node` 가 잡힙니다. 그리고
  버전이 너무 낮으면 — 리눅스에서 배포판 패키지를 그대로 쓸 때 가끔 그렇습니다 —
  첫 실행이 쓸 수 있는 버전을 알려 주고 멈춥니다. 그때 위의 버전 관리자로
  갈아끼우면 됩니다.

- **Git** — 프로그램 파일을 받아오는 것이 git 입니다. 처음 설치도, 나중의
  업데이트와 되돌리기도 git 으로 이뤄지고, 대시보드의 커밋·브랜치 기능도 여기에
  얹혀 있습니다. 없으면 설치가 시작하자마자 멈춥니다.

  맥과 리눅스에는 대개 이미 있습니다 — `git --version` 이 버전을 보여주면 그대로
  두면 됩니다. 없다고 하면 맥은 `xcode-select --install`, 리눅스는 배포판 패키지
  (`sudo apt install git` · `sudo dnf install git`) 로 넣으면 됩니다. 윈도우는
  [git-scm.com](https://git-scm.com/downloads) 에서 받거나, 위와 같은 방법으로:

  ```powershell
  winget install Git.Git
  ```

  Chocolatey 라면 `choco install git -y` 이고, 관리자 권한 조건은 위와 같습니다.

### 2. 설치

터미널(맥·리눅스) 또는 PowerShell(윈도우)에 아래 한 줄을 붙여넣으세요.

macOS/Linux:
```bash
curl -fsSL https://hyperteams.net/install.sh | bash
```

Windows PowerShell:
```powershell
iex (irm https://hyperteams.net/install.ps1)
```

받아서 바로 쓸 수 있는 상태로 들어가므로 따로 조립하는 과정이 없습니다. 설치
중에 접속 주소와 비밀번호를 물어봅니다.

### 3. 실행

어느 폴더에서든 한 단어면 됩니다.

```bash
hyperteams
```

시작하면 화면에 접속 주소가 표시됩니다 — 보통
**`http://localhost:27777`** 입니다. 브라우저에서 그 주소를 열고 비밀번호를
입력하면 끝입니다. 종료는 실행한 창에서 Ctrl-C 한 번이면 관련된 것이 모두 함께
정리됩니다.

## 이렇게 씁니다

### 어디서나 접속

처음에는 내 컴퓨터에서만 열립니다. 대시보드 **[설정] → 터널**에서 연결하면
고정 주소가 생겨 어디서든 접속할 수 있습니다 — 공유기 설정을 건드릴 필요가
없습니다. 밖으로 열리는 만큼 비밀번호를 먼저 정해야 하고, 연결한 뒤 한 번
다시 시작하면 적용됩니다.

이렇게 열어두면 폰에 앱처럼 설치해서 쓰고, 맡긴 일이 끝나면 폰으로 알림을 받을
수 있습니다. 가지고 있는 도메인을 연결하는 것도 같은 화면에서 합니다.

### 최신으로 유지하기

새 버전이 나오면 대시보드의 버전 표시 옆에 알려 줍니다. 적용은 어느 폴더에서든
한 줄입니다.

```bash
hyperteams upgrade
```

프로그램 파일만 바뀝니다 — 지금까지의 기록과 설정, 연결해 둔 주소는 그대로
있습니다. 설치를 다시 하는 것은 업데이트 방법이 아닙니다.

### 어디까지 맡길지 고르기

업무를 지시할 때 자율성의 폭을 함께 고릅니다.

| 선택 | 이렇게 동작합니다 |
|---|---|
| **파일 편집 자동 승인** (기본) | 파일 수정은 묻지 않고 진행하고, 나머지는 필요할 때 확인을 받습니다. |
| **전부 자동** | 멈춰 묻지 않고 끝까지 알아서 진행합니다. |
| **계획만** | 어떻게 할지 계획만 세워 보여주고, 실제로 실행하지는 않습니다. |
| **기본** | Claude Code의 표준 동작 그대로. |

## 관리

### 터미널을 붙잡지 않고 켜두기

그냥 `hyperteams` 로 켜면 그 터미널을 계속 쓰고 있어야 합니다 — 창을 닫으면
같이 꺼집니다. 창을 닫아도 계속 돌게 하려면:

```bash
hyperteams start --background
```

주소를 확인하고 나면 프롬프트가 돌아옵니다. 화면에 흐르던 내용은 설치 폴더의
`logs/server.log` 에 쌓이고, 직전 실행분은 `logs/server.log.prev` 로 한 세대
남습니다. 끄는 것은 `hyperteams stop` 입니다.

### 컴퓨터를 켤 때마다 자동으로 뜨게 하기

```bash
hyperteams autostart
```

로그인 항목에 걸어 둡니다 — macOS 는 launchd, Linux 는 systemd, Windows 는 시작
프로그램 폴더입니다. 끄는 것은 `hyperteams autostart off`, 지금 어떻게 되어 있는지
보는 것은 `hyperteams autostart status` 입니다.

알아 두면 좋은 네 가지입니다.

- **죽어도 되살리지는 않습니다.** `hyperteams stop` 으로 멈춘 것은 멈춘 채로 있고,
  다음 로그인에 다시 뜹니다. 자동 되살림을 켜면 그 순간 `stop` 이 무력해집니다 —
  운영체제가 "사람이 멈춘 것" 과 "죽은 것" 을 구분하지 못하기 때문입니다.
- **등록할 때의 PATH 를 그대로 박아 둡니다.** 로그인 항목은 셸 설정을 읽지 않아서,
  그러지 않으면 `claude`·`caddy`·`cloudflared` 를 하나도 못 찾습니다. node 나
  claude 를 다른 자리에 다시 설치했다면 `hyperteams autostart` 를 한 번 더 치세요 —
  그 재실행이 곧 갱신입니다.
- **사람이 로그인해야 뜹니다.** 사람 없이 부팅만으로 떠야 한다면 macOS 는 자동
  로그인을 켜야 하고, Linux 는 linger 가 필요합니다(이 명령이 알아서
  `loginctl enable-linger` 를 시도하고, 안 되면 칠 명령을 알려 줍니다).
- **macOS 의 보호 폴더를 조심하세요.** 설치본이 `~/Documents`·`~/Desktop`·
  `~/Downloads` 안에 있으면 로그인 항목은 그 폴더를 읽지 못합니다 — 손으로 띄울
  때는 멀쩡하고 자동 시작만 조용히 실패합니다. 설치본을 그 밖으로 옮기거나 전체
  디스크 접근 권한을 주세요. 해당하면 이 명령이 먼저 알려 줍니다.

### 멈추기

보통은 띄운 터미널에서 Ctrl-C 로 멈춥니다. 그 터미널이 없어졌다면 — 창을 닫았거나
접속이 끊겼거나 — 어느 폴더에서든 이렇게 멈춥니다.

```bash
hyperteams stop
```

이 설치본이 띄운 것을 전부 내립니다: 앱도, 터널도, 열어둔 터미널도. 진행 중인
작업이 있으면 알려주고 한 번 물어봅니다 — 다시 시작하면 그 작업은 이어지지 않기
때문입니다. 다시 켤 때는 `hyperteams` 입니다.

### 다시 시작하기

설정을 바꾼 뒤 적용하려면:

```bash
hyperteams restart
```

멈추고 **백그라운드로** 다시 띄웁니다 — 이 창을 붙잡지 않습니다. 꺼져 있었다면
그냥 켭니다. 이 창에 붙여서 띄우고 싶으면 `--foreground` 를 붙이세요.

### 설정 다시 하기

주소나 비밀번호를 바꾸고 싶을 때:

```bash
hyperteams setup
```

### 최신 버전으로 올리기

```bash
hyperteams upgrade
```

이 컴퓨터에 맞는 최신 빌드를 받아 프로그램 파일만 제자리에서 바꿉니다. 내
것들은 손대지 않습니다 — 데이터베이스도, `.env.local` 도, 터널 자격증명도
애초에 빌드에 들어 있지 않습니다. 실행 중이면 먼저 멈추므로, 끝난 뒤
`hyperteams` 로 다시 시작하세요.

아무것도 바꾸지 않고 새 버전이 있는지만 보려면:

```bash
hyperteams upgrade --check
```

**버튼으로도 됩니다.** 대시보드의 톱니바퀴 → *업데이트* 가 같은 일을 합니다. 쓰던
그대로 두고 새 판을 받은 뒤 한 번 재시작하고, 서버가 돌아오면 화면이 알아서
새로고침됩니다 — 터미널 없이 폰에서도 올릴 수 있습니다. (열어 둔 터미널은 닫힙니다.
그 밑의 프로그램 파일이 통째로 바뀌기 때문입니다.)

### 다른 주소로 열기

기본 번호가 이미 다른 프로그램에 쓰이고 있다면 번호를 바꿔서 실행합니다.

```bash
PORT=9000 hyperteams
```

### 삭제

```bash
hyperteams uninstall
```

설치 폴더와 `hyperteams` 명령을 함께 정리합니다. 저장된 기록도 같이 지워지므로
지우기 전에 한 번 더 물어봅니다. Claude Code 자체와 작업 폴더는 그대로
남습니다.

### 혹시 이럴 때

- **`hyperteams` 를 못 찾는다고 나오면** — 설치 직후 열려 있던 창에는 아직
  반영되지 않은 것입니다. 새 터미널 창을 열고 다시 실행해 보세요.
- **비밀번호가 기억나지 않으면** — `hyperteams setup` 으로 다시 정하면 됩니다.
- **윈도우에서 "이 시스템에서 스크립트를 실행할 수 없으므로" 라고 나오면** —
  PowerShell 의 스크립트 실행 정책이 잠겨 있는 것입니다. 위 설치 한 줄과
  `hyperteams` 명령은 여기에 걸리지 않습니다(각각 파일이 아니라 메모리에서 도는
  문자열이고, `.cmd` 입니다). 걸리는 것은 `npm`·`pnpm` 처럼 `.ps1` 형태로 들어오는
  명령들입니다. 관리자 권한 없이 아래 한 줄이면 풀립니다.

  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

  회사 PC 라 `Get-ExecutionPolicy -List` 에 `MachinePolicy` 가 `Restricted` 로
  보인다면 위 설정은 무시됩니다. 그때는 그 명령만
  `powershell -ExecutionPolicy Bypass -Command "..."` 로 우회하거나 IT 에
  요청하세요.
